# RecipePalApp
This app was created for a final project in iOS Development class.

## Project Name

RecipePal

## Project Description

This app allows users to search for recipes using the ingredients they have at home. It also allows them to save their favorite recipes in the app.

## Languages Used

Swift

## Databases Used

Google Firebase

## How to install the Project

Cloning the repo (must have Xcode and Mac)
